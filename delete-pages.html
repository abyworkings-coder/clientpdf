    Removing pages without touching the ones you keep

    Delete Pages takes a range or comma-separated list (e.g. 2, 4-6, 9) and rebuilds the PDF with just those pages removed — everything else keeps its original order, content, and formatting untouched. Unlike Split, which pulls a range out as the result, this keeps the remainder as one file, which is the more common ask when you're cleaning up a scanned document or a report with a stray blank page.

    One guardrail worth knowing: if the page list you enter would delete every page in the document, the tool blocks the operation client-side instead of handing you an empty, unopenable PDF. And like every tool here, it can only work with a PDF it can actually parse — an encrypted file will fail before deletion even starts; here's why, and what to do about a password-protected PDF.
