Common questions

Are these PDF tools actually free, or is there a catch?

Free with no catch on the tools themselves — no watermark added to your output, no daily conversion limit, no forced account. A Pro tier is planned for batch operations (processing many files at once), not for gating the individual tools above.

Do I need to install anything?

No. Every tool runs in the browser tab you're already in. Nothing to install, and nothing keeps running after you close the tab.

Is my PDF actually private?

Yes — verifiably, not just by policy. Every tool processes the file locally using pdf-lib. Don't take that on faith: here's how to confirm it yourself in 10 seconds using your browser's Network tab.

My file is huge and the tab froze — what happened?

Large files run into the constraints of the device processing them, since there's no server doing the heavy lifting instead. See why large files can freeze the tab, and how to work around it.

Not sure which tool you need? Start with Merge if you're combining files, Split if you're breaking one apart, or Compress if the file is too large to email. Every tool above shares the same rule: it never leaves your device.
