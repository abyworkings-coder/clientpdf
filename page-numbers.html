    Stamping numbers without redrawing the page

    Page Numbers overlays a running number onto each page at a corner you choose, with a configurable starting number and an option to skip the cover page — it draws the number as new content on top of the existing page, it doesn't touch or reflow anything already there. Useful for reports and packets that came from multiple source documents with no consistent numbering of their own.

    "Top-right" only means what you'd expect if the page's rotation is set to 0°. On a page that's been rotated, the corner the number lands in can end up somewhere unexpected — here's why numbers can land sideways or in the wrong corner, and how to fix it before you print or send the file out.
