    What merging actually does, and what it doesn't

    Merge takes every PDF you drop in, in the order you drop them, and concatenates their pages into one new file using pdf-lib's page-copying API — it isn't re-rendering or flattening anything, so text stays selectable, links stay clickable, and vector graphics stay sharp. Reorder the file list before you merge; there's no way to reorder pages inside the combined output afterward without a second pass through Reorder.
