    Repeating a page without retyping or rescanning it

    Duplicate Pages copies whichever pages you specify and inserts each copy immediately after its original, using pdf-lib's copyPages — useful for repeating a signature page, a cover, or a form across a longer document without rebuilding it from scratch. The page-number picker is the same range/list syntax as Delete Pages, so if you've used that one, this one will feel familiar.

    Because this grows the page count rather than shrinking or rearranging it, duplicating pages inside an already-large PDF (a hundred-plus pages, or pages full of scanned images) compounds the size the browser has to hold in memory. If a big source file makes the tab sluggish before you've even duplicated anything, this explains why, and how to keep it responsive.
