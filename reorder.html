    Dragging pages into the order they should have been in

    Reorder loads every page as a thumbnail you can drag into a new position, or drop entirely, before generating the final file — the same underlying page-copy operation as Merge and Split, just driven by a visual list instead of typed ranges. Nothing about the page content changes; only the sequence they're written back out in.
