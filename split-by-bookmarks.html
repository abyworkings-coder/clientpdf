      Splitting by structure instead of by page number

      Split by Bookmarks reads a PDF's existing outline — rather than writing one, the way Add Bookmarks does — walking the /Outlines linked list and resolving each entry's target page through either a direct /Dest array or an /A GoTo action's /D array, which covers PDFs exported from Word or LibreOffice as well as ones built with pdf-lib. Each bookmarked section is then extracted as its own file, running from one bookmark to the next (or to the end of the document).

      This only works if the source PDF has bookmarks to read in the first place. If you merged several files and the combined document came out with no outline at all, here's why merging drops bookmarks by default, and how to rebuild them with Add Bookmarks first — then this tool has something to split on.
