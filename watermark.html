    Stamping text without touching the page underneath

    Watermark draws your text across every page using pdf-lib's native drawText, with control over opacity and rotation angle — it's additive, layered on top of the existing content rather than replacing or reflowing it, so the original page is fully intact underneath if you ever need to remove the watermark by regenerating from the source file.

    Because it's drawn text rather than a burned-in image, the watermark stays crisp at any zoom level and adds only a few bytes per page to the file.
