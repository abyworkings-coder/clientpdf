    Adding blank pages exactly where you need them

    Insert Blank Pages adds new, empty pages before the first page, between any two existing pages, or at the end — sized automatically to match the neighboring page, so a blank inserted into a Letter-size document doesn't quietly become A4. Multiple insert positions are applied in descending order internally, so queuing up several inserts at once doesn't shift the page numbers you already specified for the others.

    This is a structural edit only — it adds pages, it doesn't touch the content of any existing one, and it works the same way whether the source PDF has text, scans, or forms. The one thing it can't do anything about is a file that's encrypted before you ever get to insert into it; here's why a password-protected PDF won't open in any browser-based tool, this one included.
